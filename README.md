# Linux Server Toolkit
Purpose: Bash scripts for monitoring and backing up Linux servers.

## Project structure
scripts/ - admin scripts, docs/ - documentation

## Development workflow
Branch from main, commit, open Pull Request, review, merge.

## Branching strategy
main - stable only. feature/* - new work. fix/* - fixes and reverts.

## Contribution process
Small commits, PR with what/why/tested, one review before merge.

## Testing process
Run the scripts manually and check the output.

## Troubleshooting process
See docs/TROUBLESHOOTING.md
